# Source and rights

This is a new owner-approved public source baseline. The original private
repository and all historical Git objects remain private. Commercial font binaries,
private environment files, installed state and legacy review uploads are excluded.
The project currently carries no general reuse license (`UNLICENSED`).

The copied Mac controller is derived from Zenith Research Hub and retains its
upstream MIT notice in profiles/process-macos/LICENSE.upstream. That MIT grant
applies to the imported upstream source; it does not silently license all other
project files. Npm dependency notices remain with their packages.
